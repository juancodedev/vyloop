## Pilares de Capacidad
1. **Customer Platform:** Perfil 360°, identidad unificada, consentimientos (GDPR-ready).
2. **Growth Platform:** Motor de recompensas (cashback, puntos, niveles).
3. **Communication:** Orquestador de canales (WhatsApp, Email, Push).
4. **Automation:** Workflow builder (If This, Then That + IA).
5. **AI/Data:** Motor de predicción de abandono, Business Copilot, Analytics.
6. **Developer:** API pública, Webhooks, Marketplace de plugins.
