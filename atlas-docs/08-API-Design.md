1. Filosofía de APIAPI-First: La interfaz web (dashboard) y la aplicación móvil consumen exactamente los mismos endpoints públicos que consumirá un desarrollador externo.  RESTful con extensiones GraphQL: REST para recursos transaccionales (CRUD de clientes, pagos) y GraphQL para consultas complejas de agregación y reportes.  Versionamiento: URI versioning (/v1/, /v2/). Nunca se introducen cambios breaking en versiones activas.  Estándar de Respuesta: JSON plano, utilizando códigos de estado HTTP estándar (200, 201, 400, 401, 403, 404, 429, 500).2. Autenticación y SeguridadProtocolo: OAuth 2.0 + OpenID Connect (OIDC).  API Keys: Generadas por negocio, con scopes granulares (ej: read:customers, write:loyalty, admin:billing).Multi-tenancy: El X-Business-ID es obligatorio en el header para todas las peticiones, validado contra el token de acceso.  3. Estructura de Endpoints (Dominio de Recursos)Identity PlatformPOST /v1/auth/token: Autenticación y obtención de JWT.GET /v1/me: Información del usuario autenticado y sus permisos.Customer PlatformGET /v1/customers: Lista de clientes (soporta filtros avanzados de segmentación).POST /v1/customers: Registro de nuevo perfil de cliente.GET /v1/customers/{id}: Perfil 360° (eventos, puntos, historial).PATCH /v1/customers/{id}: Actualización de datos de perfil.Growth PlatformPOST /v1/loyalty/points/assign: Asignación automática de puntos (evento PointsAssigned).  POST /v1/loyalty/rewards/redeem: Ejecución de canje de premios.GET /v1/loyalty/tiers: Consulta de niveles de membresía activos.Automation & CommunicationPOST /v1/automation/workflows: Creación de flujos de trabajo personalizados.POST /v1/communication/send: Envío omnicanal (WhatsApp/Email/Push) basado en templates.  Analytics & AIGET /v1/analytics/cohorts: Análisis de retención por cohortes.GET /v1/ai/copilot/query: Consulta semántica al Business Copilot.4.
